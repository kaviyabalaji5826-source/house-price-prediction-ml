House Price Prediction using Machine Learning

Project Overview

This project uses machine learning to analyze housing data and predict median house prices using a Linear Regression model.

Objective

To explore housing data, identify important features that influence house prices, and build a predictive model.

Dataset

The dataset contains housing-related features such as income, population, location, and housing characteristics.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow

1. Data loading
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Feature selection
6. Model training using Linear Regression
7. Model evaluation using MAE, MSE, RMSE, and R²

Model

Linear Regression

Results

The model performance is evaluated using regression metrics to understand its prediction accuracy.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.
